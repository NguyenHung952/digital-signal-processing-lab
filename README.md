# 📊 Digital Signal Processing Lab

Web-based learning/lab interface for **Digital Signal Processing (DSP)** concepts.

## 📂 Cấu trúc

```text
digital_signal_processing_lab/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🎯 Mục tiêu

- Minh họa các khái niệm xử lý tín hiệu số
- Thực hành và quan sát kết quả trực tiếp trên giao diện web
- Làm nền tảng cho các bài lab DSP mở rộng

## 🛠 Công nghệ

- HTML5
- CSS3
- JavaScript

## ▶️ Chạy

Mở `index.html` bằng trình duyệt hoặc chạy bằng static web server.

> Chỉ cập nhật README; mã nguồn HTML/CSS/JavaScript hiện có được giữ nguyên.
