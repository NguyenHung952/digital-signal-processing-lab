# digital_signal_processing_lab
Digital Signal Processing Lab là nền tảng học và phân tích DSP realtime toàn diện bằng Python (NumPy, SciPy, PyQt). Dự án hỗ trợ từ cơ bản (FFT, FIR/IIR, mô phỏng ADC/DAC, vẽ đồ thị) đến nâng cao (BER, ASK/FSK/PSK, OFDM). Lab tích hợp công cụ SDR (GNU Radio, RTL-SDR) phân tích tín hiệu WiFi và định hướng mở rộng AI Noise Reduction cho khóa luận.
