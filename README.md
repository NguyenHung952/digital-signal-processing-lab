# 📖 Giới thiệu

**Digital Signal Processing Lab** là một hệ thống mô phỏng và phân tích DSP phục vụ học tập, nghiên cứu và phát triển các ứng dụng xử lý tín hiệu số realtime.

Project tập trung vào:

- 📈 Phân tích tín hiệu
- 🎵 Xử lý âm thanh
- 📶 Truyền thông số
- 📡 Software Defined Radio (SDR)
- ⚡ DSP Realtime Pipeline
- 🧠 Ứng dụng AI trong DSP

Hệ thống phù hợp cho:

- DSP Engineering
- Wireless Communication
- SDR Research
- Audio Processing
- Embedded AI
- Realtime Signal Analysis

# ⚙️ Chức năng chính

## 📌 Signal Analysis
- Bộ phân tích tín hiệu bằng FFT
- Hiển thị phổ tần số âm thanh
- Phân tích nhiễu tín hiệu
- Tạo oscilloscope mini bằng Python
- Vẽ đồ thị tín hiệu sin/cos

## 📌 DSP Simulation
- Bộ lọc số FIR đơn giản
- Bộ lọc số IIR đơn giản
- Mô phỏng lấy mẫu ADC
- Mô phỏng DAC bằng đồ thị
- Giải bài toán DSP bằng Python

## 📌 Digital Communication
- Phân tích BER trong truyền thông số
- Mô phỏng ASK/FSK/PSK
- Mô phỏng OFDM cơ bản

## 📌 SDR & Wireless
- Phân tích tín hiệu WiFi SDR
- Thu tín hiệu realtime bằng RTL-SDR
- GNU Radio pipeline
